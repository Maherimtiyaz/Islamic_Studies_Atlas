# Islamic Studies Atlas

A structured self-study path through the Islamic sciences, in the classical order: usūl before furūʿ, method before volume, primary texts first.

- **Start here:** practical basics (tajwīd, fiqh of worship, Sīrah, the Forty Ḥadīth, purification of the heart)
- **Year 1 (6 months):** manhaj, ʿaqīdah, uṣūl al-fiqh, ḥadīth sciences, Qurʾānic sciences and tafsīr, then fiqh, history, sects and tazkiyah
- **Year 2 (4 quarters):** advanced ʿaqīdah, uṣūl, ḥadīth, and Qurʾān/history/tazkiyah
- **Year 3:** one specialization (fiqh, tafsīr, ʿaqīdah or ḥadīth)
- **Arabic** runs alongside the whole way

Every topic has key ideas, lectures, primary texts, articles and commentaries, notebook exercises and study tools. Each phase ends with a written milestone. There is a topic map with a study-path panel, focus mode, three reading modes (Light, Paper, Night) and adjustable text size.

It is one static file (`index.html`) with no build step and no accounts. Progress is saved in your browser.

## Use it

- **Offline:** open `index.html` in any browser.
- **Online:** this repo deploys itself to GitHub Pages with `.github/workflows/deploy.yml` on every push to `main`. In *Settings → Pages*, set *Source* to **GitHub Actions** if it is not already.

This path builds literacy in the Islamic sciences. It is not a substitute for qualified scholars when you need a ruling.
